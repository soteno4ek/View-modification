# Задание 9. Модификация представлений

## Поставленная задача

В своей предметной области найти три таблицы, представляющие собой связь типа М:М. Таблица-связка, помимо внешних ключей, должна иметь по крайней мере один дополнительный атрибут. Создать представление, объединяющее таблицы, соединённых связью М:М, но не включающее идентификаторы. 

Написать триггеры для представления, которые 
• при вставке нового кортежа в отношение вставляют новые записи в исходные таблицы, если они там ранее отсутствовали;  
• при обновлении обновляют соответствующие записи в таблице-связке;  
• при удалении удаляют соответствующие записи в таблице-связке.  
Провести тестирование корректности работы программы.

## Отчет о тестировании

В качестве связи М:М были выбраны таблицы `Teachers` и `Subjects` через связующую таблицу `TeacherSubjects`. В таблицу-связку добавлен дополнительный атрибут `is_main` (является ли предмет основным для репетитора). Было создано представление `v_teacher_subjects`, объединяющее имена репетиторов, названия предметов и флаг основного предмета (без ID)
